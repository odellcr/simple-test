How this simulation works

  • Events are selected randomly from weighted pools and varied by the current state.
  • Choices change resources and can create follow-on events.
  • IT, adventure, and political events can overlap on the same day.
  • The browser saves progress locally. GitHub Pages hosts the app but does not sync saves between devices.
